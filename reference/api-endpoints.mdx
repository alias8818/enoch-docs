# API endpoints

This page maps the main endpoint groups present in the local source snapshot. It is not a generated OpenAPI reference; verify request and response models against the code before building clients.

## Authentication

Unauthenticated routes include `GET /healthz`, `GET /dashboard`, and `GET /favicon.ico`. Dashboard data APIs and most control-plane routes require a bearer token or an explicit token bootstrap path where the dashboard code supports it.

```http
Authorization: Bearer <omx_inbound_bearer_token>
```

## Root app endpoints

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/healthz` | App health check. |
| `GET` | `/dashboard` | Main dashboard HTML. |
| `GET` | `/dashboard/api` | Dashboard JSON summary. |
| `GET` | `/dashboard/api/run/{run_id}` | Run detail for dashboard views. |
| `POST` | `/dashboard/queue-snapshot` | Import/update dashboard queue snapshot data. |
| `POST` | `/dashboard/paper-snapshot` | Import/update dashboard paper snapshot data. |
| `GET` | `/project-status/{project_id}` | Project status. |
| `POST` | `/prepare-project` | Prepare a project workspace. |
| `POST` | `/dispatch` | Lower-level dispatch endpoint. Prefer `/control/dispatch-next` for control-plane dispatch. |
| `POST` | `/omx/event` | Incoming completion/event callback path. |

## Control-plane endpoints

The control router is mounted under `/control`.

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/control/health` | Control router health. |
| `GET` | `/control/state` | Control state and flags. |
| `GET` | `/control/api/status` | Dashboard status with flags, blockers, and config state. |
| `GET` | `/control/api/queue-health` | Queue health summary. |
| `GET` | `/control/api/queues/{queue}` | Queue view. |
| `GET` | `/control/api/projects/{project_id}` | Project detail. |
| `GET` | `/control/api/runs/{run_id}` | Run detail. |
| `POST` | `/control/api/preflight` | Worker preflight check. |
| `POST` | `/control/worker/preflight` | Worker preflight check alias. |
| `POST` | `/control/dispatch-next` | Guarded dispatch, including dry-run. |
| `POST` | `/control/pause` | Pause queue or enter maintenance depending on payload. |
| `POST` | `/control/resume` | Resume queue or exit maintenance depending on payload. |
| `POST` | `/control/queue/mark-paused` | Mark a queue item paused. |
| `GET` | `/control/export/snapshot` | Export control-plane snapshot. |

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/enoch-core/health` | Core health. |

## Client guidance

Use `/control/api/status`, `/control/api/preflight`, and `/control/dispatch-next` for normal dispatch automation. Treat root `/dispatch` as lower-level compatibility surface unless the source code for your version says otherwise.
