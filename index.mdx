# Enoch docs

Enoch is an agentic research control plane. It queues research ideas, checks whether a worker is safe to use, supervises long-running local AI jobs, preserves evidence, and packages AI-generated research artifacts with explicit provenance.

These docs are written for new operators, contributors, and reviewers. They are intentionally conservative: when a behavior is not evidenced in the code repository, corpus repository, Hugging Face export, or release notes, the docs either omit it or call it a limitation.

## What is in the release snapshot

The local project snapshot used for this docs pass contains:

- `enoch-agentic-research-system`: the FastAPI control-plane and wake-gate code, deployment helpers, tests, and source docs.
- `enoch-ai-research-corpus`: a corpus repository of AI-generated research artifacts with `paper.md`, `metadata.json`, `evidence_bundle.json`, `claim_ledger.json`, and `paper_manifest.json` files.
- `hf-enoch-ai-research-corpus`: a Hugging Face dataset export with `data/artifacts.jsonl` and `dataset_summary.json` reporting 159 artifacts.
- `RELEASE_STATUS.md`: a dated staging note that records secret-scan evidence and remaining release gates from April 28, 2026.

## Important caveat

The generated reports are AI-generated research artifacts, not peer-reviewed scientific claims and not human-authored papers. Use them for inspection, critique, replication planning, and workflow research; do not cite them as validated science without independent review.
